# Magesh S. — Portfolio

A responsive personal portfolio built with React, Vite, and Bootstrap.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to GitHub Pages

The project is configured for the repository's GitHub Pages URL:
<https://ms1326.github.io/Portfolio/>.

1. Push the project to the `main` branch on GitHub.
2. Publish the site (and update it after future changes) by running:

   ```bash
   npm run deploy
   ```

   This builds the app and publishes the contents of `dist` to the `gh-pages` branch.
3. In the repository, open **Settings → Pages**, set the source to **Deploy from a branch**, select the `gh-pages` branch and the `/(root)` folder, then save.

Project links and profile links point to the public GitHub and LinkedIn profiles.
